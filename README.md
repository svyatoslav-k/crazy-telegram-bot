# Telegram Bot для организации тренировок и деления на команды

Проект деплоится с помощью **Docker** и **Docker Compose**

## 🚀 Основной функционал

1. **Автоматический опрос:** Каждый понедельник в **15:00** (нужно учитывать часовой пояс сервера, на котором запущен контейнер) бот автоматически публикует в чат опрос, к примеру: *"Играешь в среду?"*.
2. **Гибкие варианты ответов:** Поддерживаются голоса за себя и за друзей:
   * `Да` / `Нет`
   * `Да, со мной +1` / `Нет, от меня +1` (учитывается при формировании команд)
3. **Умное разделение:** Рандомно распределяет всех проголосовавших (кроме `Нет` естественно) по командам с учётом «плюсов».

## 💬 Команды управления (Текстовые триггеры)

Бот реагирует на следующие текстовые сообщения в чате:
* **`привет, бот!`** - активация бота, чтобы он начал отвечать на сообщения
* **`запускай`** — принудительно запускает опрос для записи на тренировку в любое время (не дожидаясь понедельника)
* **`подели`** — обрабатывает текущие результаты голосования и выводит рандомный состав разделенных команд
* **`очисти голоса`** — сбрасывает все внутренние переменные и результаты текущего голосования

## 🛠 Быстрый запуск через Docker

Проект уже содержит `Dockerfile` и `docker-compose.yml`, поэтому запуск занимает всего пару минут

### 1. Подготовка окружения
Создайте файл `.env` в корневой директории проекта и добавьте туда ваш токен (убедитесь, что `.env` добавлен в ваш `.gitignore`):

```env
TELEGRAM_TOKEN=ваш_токен_от_botfather
```

### 2. Запуск контейнеров
Соберите (или скачайте, тогда без --build) образ и запустите бота в фоновом режиме (detached mode):

```bash
docker compose up -d --build
```

### 3. Проверка работы
Чтобы посмотреть логи работы бота и убедиться, что всё запустилось без ошибок:

```bash
docker compose logs -f
```

### 4. Остановка бота
Если нужно остановить и удалить контейнер:

```bash
docker compose down
```

## 📂 Структура репозитория

* `Dockerfile` — инструкции для сборки Docker-образа приложения
* `docker-compose.yml` — конфигурация для быстрого развертывания и управления контейнером
* `.gitignore` — исключает из отслеживания Git конфиденциальные данные (например, `.env`)
* `.dockerignore` - исключает эти файлы при сборке образа
* `requirements.txt` - зависимости для python
* `main.py` - основной функционал
* `README.md` - описание
